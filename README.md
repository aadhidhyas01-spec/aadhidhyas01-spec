### 🚛 CivicLens AI — Smart Automated Waste Management

An ongoing project exploring an AI-assisted waste collection system using computer vision, wireless control and robotic manipulation.

- **Vision:** YOLO-based waste detection experiments and camera streaming.
- **Embedded control:** ESP32-CAM and ESP32 DevKit prototypes.
- **Robotics:** mobile robot and robotic-arm control experiments.
- **Simulation:** ROS 2 and Gazebo city-collection concept.
